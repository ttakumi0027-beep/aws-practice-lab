## 構築手順

### 1. ホストゾーンの設定

- ドメインの取得（お名前.com）
- ホストゾーンにドメインを登録
- お名前.comに、NSレコードを登録
- EC2インスタンスのパブリックIPアドレスをAレコードに登録
- ドメインの確認

```bash
# IPアドレスが返ってくること
nslookup <ドメイン名>
```

### 2. シンプルルーティングの検証

- インスタンスのAMIを作成
- AMIをシンガポールとシドニーにコピー
- AレコードにシンガポールとシドニーのパブリックIPを追記
- 各サーバのindex.htmlの修正
- 下記のように書くリージョン間でシンプルルーティングできていることを確認

## 学んだこと

- DNSサーバはネームサーバとリゾルバで構成されている
- ネームサーバはドメインとサーバを結びつける名前解決をするサーバ
- リゾルバはドメインに紐づけられたIPアドレスが問われたら、ドメインに関連づけられたネームサーバを指定して名前解決してくれるサーバ
