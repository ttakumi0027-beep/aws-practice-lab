## 構築手順

### 1. S3バケットの公開方法

- S3（test-s3-20260225）を作成
- Testフォルダを作成し、画像ファイルを配置
-　パブリックアクセスのブロック解除とACLをパブリックに編集
- アップした画像が表示されることを確認

### 2. ライフサイクルポリシー

- バケットのバージョニングの有効化
- バージョニング有効化確認

（Test.rtfファイルをアップロード後、編集をかけて再アップロードした）

### 3. アクセスログの有効化

- AccessLogフォルダを作成
- 

### 4. イベント通知設定方法

- イベント（S3_event）の作成し、SNSへ通知設定
- SNSへ通知できるかかくにん



<details>
<summary>バケットポリシー（JSON）</summary>
  
```JSON
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "Service": "vpc-flow-logs.amazonaws.com"
            },
            "Action": "sts:AssumeRole"
        }
    ]
}
```

</details>

## 学んだこと

- S3アクセスポイントを作成することで、複数のアクセスポリシーを設定できる。バケットポリシーは、一つのバケットに対してしか作成できない
- S3バケット操作時をトリガーとして、別のAWSサービスを連携できる
