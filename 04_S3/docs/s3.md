### 7.AWS CLIの導入方法

- AWS CLIのインストール（https://docs.aws.amazon.com/ja_jp/cli/latest/userguide/getting-started-install.html）

```bash
aws --version
aws-cli/2.33.31 Python/3.13.11 Darwin/24.6.0 exe/arm64
```
- IAMユーザより、アクセスキーとシークレットキーの作成及び登録

```bash
# アクセス、シークレットキーの登録
aws configure

# AWSバージョンが確認できる
~ $ aws --version
aws-cli/2.33.31 Python/3.13.11 Darwin/24.6.0 exe/arm64
```
- S3バケットをCLIで作成
```bash
~ $ aws s3 mb s3://aws-cli-20260301
make_bucket: aws-cli-20260301
```

## 学んだこと

- S3アクセスポイントを作成することで、複数のアクセスポリシーを設定できる。バケットポリシーは、一つのバケットに対してしか作成できない
- S3バケット操作時をトリガーとして、別のAWSサービスを連携できる
- ライフサイクルを利用して、S3バケットの利用料金を最適化できる
